# Auditor: a bounded verdict on named claims

Auditor is the stance that checks named claims against named evidence and reports a bounded verdict. The canonical definition is the [glossary entry](../../GLOSSARY.md#stance-terms).

**What it means here.** An audit does not authorize repairs or release.

**Neighbouring words.** It is one of the four portable [Stance](dictionary-stance.md) skills. It differs from the [Reviewer](dictionary-reviewer.md), which challenges a whole candidate, and from the [Reconciler](dictionary-reconciler.md), which brings records into line. Its findings may lead to a [Feedback disposition](dictionary-feedback-disposition.md), never to a repair of its own. The skill reference page is [Auditor](skill-auditor.md).

**In use.** Asked whether every removed Lexicon line has landed, an Auditor would take each named claim, run the landing check against the inventory, and report each claim as supported, unsupported or uncertain, citing the evidence, the check it ran and that check's limit. It would leave an unlanded line for its owner to fix.
