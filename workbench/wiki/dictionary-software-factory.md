# Software factory: sessions started by triggers, not people

A software factory is a system in which triggers, not a person, start agent sessions, so more work runs while nobody is watching. The owner adopted the term from the AI Coding Dictionary on 2026-10-03.

**What it means here.** It is the closest dictionary term for what the owner calls the Foundry, an autonomous factory of many rooms. The glossary's Foundry entry names the owner's own factory; this page names the general idea.

**Where the Workbench depends on it.** The Foundry decision builds every workbench to run as one room among many in such a factory, which is why a room must be portable, its work claimable by any agent, and its proof checkable without the owner present.
