# Wiki profile: the manifest's declared Wiki shape

The Wiki profile is the shape of Wiki the manifest declares: `project`, one room's memory router and collections, or `deployment`, which adds owner, machine and project pointer collections. The canonical definition is the [glossary entry](../../GLOSSARY.md#governance-core).

**What it means here.** A profile declares routing shape; it grants no authority and copies no live task state.

**Neighbouring words.** It is declared by the [Support root](dictionary-support-root.md)'s manifest and shapes which [Collections](dictionary-collection.md) the Wiki has. [Design Concept articles](dictionary-design-concept-article.md) exist under either profile.

**In use.** This room's manifest declares `wiki.profile: project`, and Wiki `MEMORY.md` says so: the product repository keeps no personal, machine or deployment notes.
