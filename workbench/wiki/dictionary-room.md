# Room: a project seen as the place its work happens

A room is a project, seen as the place its work happens. The workbench is the
table set in it; agents take what they need from the table and work on the
project in the center. The canonical definition is the [glossary
entry](../../GLOSSARY.md#workbench-room-and-artifacts).

**What it means here.** Room has always meant project, so it is not the Workbench: the Workbench entry says it is the table set in one ([the room and table decision](../docs/ddr/000U-a-project-is-a-room-and-the-workbench-is-the-table-in-it.md)). Environment and Filesystem are sibling definitions of Room, in the owner's words: "File system, and Environment are going to be some sibling definitions to this one." Rooms nest ([the nesting decision](../docs/ddr/000W-rooms-nest-and-a-parent-workbench-owns-what-its-children-share.md)). Not a Chat, a Conversation or a host.

**Neighbouring words.** The [Project](dictionary-project.md) is the same thing
seen as the work; the [Workbench](dictionary-workbench.md) is the table in it.
[Environment](dictionary-environment.md) and
[Filesystem](dictionary-filesystem.md) are its sibling definitions. A
[Chat](dictionary-chat.md) and its [Conversation](dictionary-conversation.md)
happen in a room but are not it, and every new room starts from the [Workbench
Template](dictionary-workbench-template.md).

**In use.** "Every room's Blueprint is the four-part short page" means every
project made from the Template, this one included ([the short page
decision](../docs/ddr/000N-every-room-s-blueprint-is-the-four-part-short-page.md)).
The maintainer [`workbench-room-checks`
skill](../skills/workbench-room-checks/SKILL.md) checks how this repository lays
out, installs, adopts and upgrades a room.
