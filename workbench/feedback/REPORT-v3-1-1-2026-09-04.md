## Findings

### F-004 — High: the required Wiki verification is not CRLF-portable

- **Location:** `tools/test-wiki.mjs:42`, `:100-102`, `:129-130`, and `:228`.
- **Claim:** A normal Windows checkout with CRLF working-tree files cannot pass the required Wiki verification, despite the harness's Windows/POSIX portability claim.
- **Reproduced effect:** `test-wiki.mjs` assumes `\n` in frontmatter assertions and regex replacements. The initial template-frontmatter check fails before exercising behavior. The Genesis-readiness fixture also fails because its LF-only substitutions leave placeholder rows intact. The resulting seeded-Wiki and dogfood validations then fail with four `invalid-note` errors. Only 2 of 7 checks pass.
- **Why this is harness-caused:** Git reports the repository's affected files as `i/lf w/crlf`; the test reads those files as-is and makes LF-only text assumptions. This is neither an external service failure nor an application-specific fixture issue.
- **Smallest bounded next action:** With owner authorization, create a narrowly scoped portability repair that normalizes test fixture text before line-oriented matching/replacement, or changes the patterns to accept `\r?\n`; add a red/green CRLF fixture covering both frontmatter and router placeholder removal. Preserve the production parser's existing behavior and the test's intended assertions.

### F-005 — Low: dogfood Wiki provenance remains stamped v3.0.0

- **Location:** `workbench/wiki/AGENTS.md:15`, `workbench/wiki/SCHEMA.md:15`, and `workbench/wiki/design-concepts/README.md:15`.
- **Claim:** The dogfood Wiki contract's generated-from stamps disagree with the live v3.1.1 manifest and root controls.
- **Reproduced effect:** the three files say `Generated from LLM Workbench v3.0.0`, while `workbench/manifest.json`, `BLUEPRINT.md`, and `README.md` identify v3.1.1. S-027 already records this as review limitation P3-1 and confirms no diagnostic currently checks these Wiki stamps.
- **Smallest bounded next action:** If the owner wants generated-provenance consistency, update the three dogfood stamps and add a version-alignment check scoped to seeded Wiki contract files. This is documentation integrity work, not release evidence.
