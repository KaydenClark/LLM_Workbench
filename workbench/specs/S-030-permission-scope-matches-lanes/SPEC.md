# S-030 - Permission Scope Matches Declared Lanes

**Status:** active
**Priority:** 1
**Owner:** unassigned

**Catalog description:** Ship a template permission file that grants Edit and Write on the Workbench authorship lanes the prose already declares writable, and make doctor report when a room's permission file withholds a declared lane.
**Blockers:** none

## Outcome

A room generated or adopted with `.claude/` copied in can record its own ADRs,
specs, wiki pages, feedback rows, and checkpoints without an agent stalling on
an ungranted write, and a permission file that disagrees with the manifest's
declared lanes is a named finding rather than a silent stall.

## Why It Matters

`templates/AGENTS.md:84` declares the `workbench/` support lanes writable in
prose. `templates/.claude/settings.json`, the mechanical half of the same
scope, never mentions `workbench/` and carries no `Write(...)` rule in its
`allow` bucket for any path at all, only `Edit(...)` (its two `Write` rules
are denies). Edit revises a file that exists; Write creates
one. Under the shipped template every new `SPEC.md`, ADR, wiki page, and
promoted checkpoint is an ungranted write while the controls say the lane is
writable. Master Workbench, generated by Genesis v3.1.1, carried exactly this
defect until 2026-09-05 (`~/Master_Workbench/data/upstream/v3.1.1.json`,
UP-012, rank `high`): it passed `doctor`, `verify`, and its 88-test suite in
that state and was found only when the owner reported that the room could not
update itself. Every other Genesis- or Adoption-generated room that copied
`.claude/` still has it.

Gap: everything under Desired Behavior.

## Desired Behavior

1. `templates/.claude/settings.json` grants `Edit` and `Write` on
   `workbench/specs/`, `workbench/docs/`, `workbench/wiki/`,
   `workbench/feedback/`, and `workbench/sessions/`; holds
   `workbench/tools/**` in `ask` for both Edit and Write; pairs `Write` with
   every `Edit` on the writable roots; adds `Edit(./LEXICON.md)`; and grants
   `Bash(node workbench/tools/spec-workbench.mjs:*)`, `adr.mjs`,
   `sessions.mjs`, `wiki.mjs`, and `workbench-layout.mjs`.
2. `templates/.claude/README.md` states that Edit and Write are separate
   grants, that creating a record needs Write, and lists the authorship lanes
   as a fourth row of the mapping table. `templates/GENESIS.md` and
   `templates/ADOPTION.md` Phase 4 say "writable roots and the Workbench
   authorship lanes -> allow (Edit and Write)".
3. `doctor` reports `permission-scope-drift` (severity `error`, scope
   `controls`, effect `none`) when `.claude/settings.json` exists and any
   manifest lane other than `tools` lacks a covering `Edit` and `Write` allow
   rule, is covered by a `deny` rule, or the `tools` lane appears in `allow`.
   The finding names each withheld lane. `validate --genesis` fails closed on
   it when the file exists; a room without the file is unaffected.
4. The Genesis and Adoption completion boxes read "filled from that scope and
   grants Edit and Write on the declared authorship lanes, or `.claude/` was
   omitted with a reason".

## Decisions And Contracts

- **Prose and mechanism must agree, and the mechanism is checked.** The
  permission file is the mechanical half of `AGENTS.md` Edit Scope; a lane the
  manifest declares that the file withholds is drift, reported by the same
  doctor that reports render drift.
- **`workbench/tools/` is `ask`, not absent.** Managed runtime tools change
  only through the explicit Workbench update (ADR-0031); the permission file
  says so rather than staying silent.
- **Report, do not rewrite.** The diagnostic never edits a room's permission
  file; a room may legitimately deny a lane and record why.
- **Conservative matcher.** The check recognizes `./<lane>/**` and a covering
  parent glob such as `./workbench/**`; anything else is treated as not
  granting, so a false "drift" is possible but a false "granted" is not.

## Non-Goals

- Repairing downstream rooms' permission files.
- Modeling the full Claude Code permission grammar or other agents' permission
  systems; Codex and Gemini read the prose scope.
- Adding a `.claude/settings.json` to this repository, which relies on the host
  permission layer and says so in `CLAUDE.md`.
