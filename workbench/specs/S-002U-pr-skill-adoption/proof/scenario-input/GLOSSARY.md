# Glossary (scenario fixture)

Scenario fixture for S-002U TK-007W only. The room's canonical `GLOSSARY.md` is not delivered yet; Lexicon Retirement And ARCHITECTURE.md (S-004O) owns that. These meanings are condensed from the room's current `LEXICON.md` rows of the same names.

| Term | Meaning |
|---|---|
| **Room** | A project, seen as the place its work happens. The Workbench is the table set in it. |
| **Skills lane** | The manifest-declared lane `workbench/skills`: the skills tracked inside the room, owned and versioned by LLM Workbench and replaced only by a Workbench update. |
| **Core skill bundle** | The closed, manifest-counted set of required skills every room carries in its Skills lane, reached through the tracked `.agents/skills` and `.claude/skills` adapters. |
| **Spec** | A scoped objective with its own destination; it owns requirements, acceptance, verification and evidence while delivery needs it. |
| **Task** | One bounded vertical slice of a Spec, with its own state, proof and blockers. |
