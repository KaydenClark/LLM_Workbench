# LLM Workbench is the producer and the Workbench Template is its product

Landmark: Workbench Template.

LLM Workbench is the producer and the Workbench Template is its product: the Template is what this project makes. A new project starts from the Template, and a project already under way has the same workbench attached. If the Template does not work, LLM Workbench has not delivered.

Why the owner chose it: The owner, in his own words (2026-10-03, teardown round 1): "Why do we prove our releases through the template workbench needs to be recorded somewhere. Its because Producer:LLM_Workbench and Product:Template_workbench The template workbench is what this project produces. If that does not work, what are we working on?"

Considered and rejected: None recorded.

Consequences: None recorded as owner words. An adjacent accepted record covers source ownership, not this relationship: [LLM Workbench is the sole Workbench source; Foundry is a downstream extension](../adr/0026-workbench-is-the-sole-source-and-foundry-extends-it.md).
