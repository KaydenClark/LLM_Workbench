# Every workbench is built to run as one room among many in an autonomous factory, the Foundry

Landmark: none, Blueprint level.

Every workbench is built to run as one room among many in an autonomous factory, the Foundry.

Why the owner chose it: The owner, in his own words (correction on the round-4 card, 2026-10-03): "The workbench is not the foundry yes, but say what that means. The workbench is a management system. the foundry was an autonomous factory. how they related is the Foundry was a factory of many rooms, each with a workbench producing work. The workbench is still designed to work like this. and we will still need it for the foundry. The foundry needs us to prove it works through."

Considered and rejected: The earlier non-goal wording that only said what the Foundry relationship is not (no portfolio scheduler, no replacement for Command Information Center, no Foundry machinery). The owner: "This doesnt belong on the blueprint stated like this."

Consequences: None recorded as owner words. Accepted records that already cover the Workbench's independence from the Foundry, not restated here: [Workbench supplies the base and Foundry adds coordination](../../adr/0015-workbench-base-and-foundry-capabilities.md) and [LLM Workbench is the sole Workbench source; Foundry is a downstream extension](../../adr/0026-workbench-is-the-sole-source-and-foundry-extends-it.md). The Lexicon term for the Foundry (locked as "Software factory") belongs to the terms work.

Provenance: the Blueprint teardown grilling of 2026-10-02 to 2026-10-03: question WHY-D10a (the Foundry sentence, locked 2026-10-03 on the round-7 card, where the Command Information Center line was also removed because a name the page does not explain means nothing to an agent reading it), with the owner's correction of 2026-10-03 quoted above.
