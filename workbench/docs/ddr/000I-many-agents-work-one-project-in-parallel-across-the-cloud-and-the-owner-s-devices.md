# Many agents work one project in parallel, across the cloud and the owner's devices

Landmark: Work from anywhere.

Coordinated parallel work on one project is a goal of the Workbench. The workbench keeps the context so each agent resumes where the last session left off, and it keeps many agents coordinated on the same project at once, in cloud worktrees and on the owner's own machines, so the owner can work on one project from many devices.

Why the owner chose it:

- The owner's confirmed reasons: Parallel work is how the owner steps away after confirming and comes back to a finished product: one agent in one session cannot carry a confirmed concept to its endpoint inside its smart zone, so the work is divided and run at once.
- Agents in different harnesses, Claude Code and Codex, delegate work and exchange results. The owner's confirmed reason: Claude Code and Codex are the harnesses the owner actually runs, and the workbench is the management system both use, so work has to pass between them without the owner relaying it.

Considered and rejected: None recorded.

Consequences: None recorded.
