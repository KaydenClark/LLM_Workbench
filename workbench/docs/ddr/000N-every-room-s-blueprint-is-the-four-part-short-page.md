# Every room's Blueprint is the four-part short page

Landmark: Workbench artifacts.

The four-part short page (what it is, who it serves, promised outcomes, non-goals) replaces the eight-section shape for every room's Blueprint, not only LLM Workbench's.

Why the owner chose it: The owner's confirmed reason: What a workbench's artifacts are is set by LLM Workbench and a project changes only what they say, so every room gets the same Blueprint shape and owns the words on it.

Considered and rejected: None recorded.

Consequences: None recorded as owner words. Accepted records that cover the page for LLM Workbench's own Blueprint, not restated here: [Landmarks are LANDMARK.md artifacts one size above Specs](../adr/000U-landmarks-are-landmark-md-artifacts-one-size-above-specs.md) and [Active ADR decisions and destination Blueprints](../adr/000A-active-adr-decisions-and-destination-blueprints.md).
