# Evidence for claims of improved agent outcomes

Claims that the harness improves agent outcomes require repeated controlled
trials, held-out tasks, condition-blind assessment, comparison with controls and
prior/candidate versions, and uncertainty. Preserve criteria and failed results.
Judge achieved state and honest incompleteness, not polished narration or a
self-score. Useful task acceptance applies to the product's actual interface.

Considered alternatives: Static conformance scores are valuable structural checks but cannot replace
observed agent outcomes. A single favorable demonstration cannot establish
reliability. Weakening criteria to raise a score destroys comparability.

Consequences: Reports separate inspection, observed use, behavioral tests and outcome evidence.
UI acceptance is required only for products with a UI; this does not impose
mobile/desktop applications on a command-line Workbench.
