# The Workbench Contract is a claim set carried by the seven controls and the assigned spec

The Workbench Contract is the logical set of current claims owned by the seven root controls plus the explicitly assigned spec. It is not a file. Exactly seven universally discoverable root harness controls exist; no `CONTRACT.md` or other coequal root control is added to hold the contract.

Considered and rejected: a single `CONTRACT.md` that restates the binding claims in one place. It would become a second, driftable copy of rules whose owners already exist, and every reader would have to decide which copy was current.

Consequences: a claim enters the contract by living in its owner; the assigned spec contributes bounded capability requirements only after selection or explicit assignment ([ADR-0025](0025-planes-classify-claims-not-whole-artifacts.md), [ADR-0027](0027-instruction-authority-is-separate-from-state-resolution.md)).

Provenance: owner-reviewed v3.1 greenlight decision, promoted 2026-09-04; see the tracked checkpoint `llm-workbench-v3-1-plan-2026-09-04.md` in the manifest-declared checkpoint collection.
