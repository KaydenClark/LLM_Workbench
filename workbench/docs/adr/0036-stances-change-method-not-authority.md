# Assigned portable stances change method, not authority

Ship Builder, Auditor, Reviewer, Reconciler with Purpose, Method / Posture, Obligations and Completion / Exit Condition. SPEC and TASK assign normal stance. Adoption never grants, removes or transfers authority or spawns an agent.

Considered and rejected: Permanent agent departments, mandatory stance selection, and a handoff per stance change create machinery unrelated to the task.

Consequences: Extend the twelve-skill workflow bundle by four flat stance skills for both providers. A nested stance installation needs a flat symlink for one-level discovery. Troubleshooting policy is deferred.
