# Visible, deliberate control divergence

Filling template placeholders preserves fixed wording unless the room
deliberately chooses a divergence. Report changed, dropped and added controls
against the matched source generation and record their disposition. Fidelity
is a report, not a universal blocker, and room-specific differences are legitimate.
Provider permission configuration and prose must be compared without assuming
that either proves native enforcement.

Considered alternatives: Blind copying erases product-specific controls. Treating all divergence as a
failure forbids valid customization. Silent divergence hides the choice and
makes a reference installation unexplained imitation.

Consequences: Example is a self-explaining conformance reference. Compare like generations
and prove actual installed behavior; a textual match cannot certify semantics,
host permissions or runtime outcomes.
