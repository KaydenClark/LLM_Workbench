# Required steps must enable direct delivery

Require an immediate delivery value and checkable artifact, decision, or risk reduction for an imposed step. If value is uncertain, retain it as optional and reviewable until owner grilling resolves it.

Considered and rejected: A universal lifecycle checklist makes compliance its own product and can delay useful output.

Consequences: Verification and safety retain their actual scope; no check is weakened for convenience.
